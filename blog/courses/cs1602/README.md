Personal notes for **CS1602 Introduction to Computing** at Shanghai Jiao Tong University. They are my own study notes, combining the course lectures with a revision sheet I wrote, and are **not official course materials**.

The notes move from how a computer represents data, through the command line and Python's data model, to control flow, functions, containers, classes, modules, exceptions, file I/O, and iterators. The source archive is kept at [JinShuo-Li/Courses](https://github.com/JinShuo-Li/Courses).
