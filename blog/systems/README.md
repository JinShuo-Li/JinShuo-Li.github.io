---
title: Systems
description: Notes on execution runtimes, heterogeneous hardware, and performance measurement.
---

Systems work is where an idea has to survive contact with a real machine. These notes cover execution runtimes, device placement, and the measurement discipline that keeps performance claims honest.

The recurring theme is that hardware is not interchangeable. Moving work between a CPU, an integrated GPU, and an NPU changes not just speed but the shape of the workload, and the only way to know the result is to measure it on the machine in front of you.
